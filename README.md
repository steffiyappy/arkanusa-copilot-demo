# Demo hub

A password protected, single page reference site used by the Microsoft
demonstration team to run a scripted product demonstration.

## What this repository contains

- `index.html` — access gate
- `hub.html` — the demonstration reference itself

## Notes

- All content behind the gate is illustrative. The account, the people, the
  figures and the documents are fictional and were generated for demonstration
  purposes.
- No customer information is held in this repository.
- Access is restricted. If you need the password, ask the person who sent you
  the link.

## Running locally

Open `index.html` in a browser, or serve the folder statically:

```
python -m http.server 8080
```
